# 医栈通微信小程序 · 开发预览 0.1.0

首版工程已建立。当前没有正式 AppID，生产账号域名留空；尚未经过微信开发者工具原生编译、真机调试或平台审核。可先导入工程体验与个人账号隔离的合成演示数据。

## 导入与体验

1. 在微信开发者工具中导入本目录，项目类型选择“小程序”。当前 `project.config.json` 使用 `touristappid`；可选择工具提供的测试号/无 AppID 模式。若当前版本工具不允许该模式，先申请自己的测试号或正式 AppID，不要填写他人的标识。
2. 直接编译，进入登录页，选择“体验演示工作区”。`lib/domain.js` 已随工程提供，导入体验不需要另装业务依赖。
3. 检查“今日、任务、日程、专注、我的”。主题和小组件统一在 **我的 → 设置**；首页没有配置入口。
4. 本机可试任务增改、四象限筛选、完成/恢复、日程添加、删除恢复、计时暂停/继续、八主题切换和四个首页组件的显隐。

`artifacts/Medstack-WeChat-0.1.0-preview.zip` 是只含可导入运行文件及说明的工程包，不包含真实账号、个人数据、测试缓存或模型密钥。项目源码和测试仍在当前目录。HTML/PNG 仅为布局辅助预览，不是微信运行截图。

## 首版功能

| 页面 | 已实现                                                     |
| ---- | ---------------------------------------------------------- |
| 账号 | 邮箱登录、注册验证、重发验证码、找回密码；未登录保护       |
| 今日 | 待办、今日专注、日程、课程缓存；手动同步                   |
| 任务 | 创建、编辑、截止日、四象限、清单、完成/撤销、可恢复删除    |

复用桌面领域规则、schema 5 文档和现有账号后台。小程序共享 `workspace.theme` 与对应 `widgets.hidden`；组件顺序、尺寸、自定义主题数据和其他工作台字段保留。桌面自定义主题暂在小程序以经典医疗配色展示，除非主动选其他主题，不改原设置。

Poseidon、学校认证、校园接口直连、成绩、自动抓取、微信订阅消息和推送未在本版接入。课表须由现有桌面端刷新并上传，不能将缺失课表解释为当天无课。

## 注册后接入

1. 将正式 AppID 写入 `project.config.json`。AppSecret 不进入小程序工程；本版邮箱账号流程无需 AppSecret。
2. 为现有 Medstack 账号后台配置经过验证的 HTTPS 域名、TLS 和相应合法域名设置，然后填写 `config.js` 的 `apiOrigin`。默认留空是有意的，不能将现有服务器 IP 填入正式请求域名。
3. 核验后台 `baseURL`、来源检查和微信请求实际携带的请求头。适配器沿用现有 Bearer 会话及 Origin 规则，未放松服务端来源验证。当前只通过本地真实后台的模拟 wx.request 接口测试，原生请求头兼容性仍须真机确认。
4. 用合成测试账号依次验收注册、验证、登录、找回、双端修改、断网重连、冲突恢复、注销及其他账号隔离，再开启正式体验版。
5. 发布前检查平台要求的服务类目、隐私配置和审核资料；按实际收集项填写。不将后台已上线等同于小程序已上线。

平台依据：[微信网络说明](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[运行机制](https://developers.weixin.qq.com/miniprogram/dev/framework/runtime/operating-mechanism.html)。本轮已通过直接读取官方网络文档核对 HTTPS 域名、不能使用公网 IP、固定 Referer 等限制。

## 数据与同步

- 邮箱密码只用于当前请求；会话令牌仅保留在内存。进程重启后需要重新登录。
- 工作区保存在微信本地存储，使用账号 ID 隔离。没有自行宣称等同于桌面系统加密；本机缓存和恢复副本包含个人工作区，不能发给他人。
- 演示工作区使用单独标识，不接云端，不使用用户真实任务或课表。
- 手动同步先确认服务端身份，再拉取版本。两端同时变化时停止覆盖；选择某一端前，先在当前账号本地保存两份恢复副本。副本键格式为 `medstack:mp:v1:<账号ID>:backup:<时间戳>`，没有自动清理；当前仅支持开发者协助恢复，未提供副本管理页面。
- 云端用版本号比较后写入。上传中再编辑会继续保留待同步状态；退出或切换账号后，迟到响应不会写入新账号。
- 正在运行的计时器仅保存在当前设备；结束后的原始专注区间进入共享文档。后台挂起后回前台以时间戳校准；后台响铃、锁屏提醒不作保证。
- 任务和日程删除使用标记，可从“我的 → 回收站”恢复。

## 开发与检查

完整仓库先安装根项目及 `server` 已声明的依赖；本轮没有增加生产依赖。在仓库根目录执行：

```powershell
npm run build --prefix miniprogram
npm run check --prefix miniprogram
npm test --prefix miniprogram
node miniprogram/scripts/preview.mjs
npm test
```

构建脚本用仓库现有 Vite 将共享领域模块打包成微信可用的 CommonJS，仅针对 UUID、JSON 深拷贝和 UTF-8 长度计算作平台适配，不修改桌面源文件。任务 ID 使用时间与随机片段生成，不承担认证用途。

静态预览用项目已有 Playwright 和 Windows Edge；其他环境可设置 `MEDSTACK_BROWSER_CHANNEL`。此检查把实际 WXML 数据与 WXSS 转成 HTML，能帮助发现页面绑定、条件显示及横向溢出，不能替代微信原生编译和 iOS/Android 真机测试。
