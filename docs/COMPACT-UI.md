# V5.1.1 界面修订

本次按用户要求采用极简界面。侧栏缩为 176 像素，顶栏缩为 44 像素；内容区使用剩余宽度，不再居中留下大块边距。七款主题和自定义主题继续可用。

首页待办与日历并排，统计和附加组件默认收起。外观分为主题、背景与配色、小组件、模块；通知分为通知、学习通连接、自动工作流。补记专注时长按需展开。

任务每行保留完成勾选和标题，专注、编辑、删除集中到“⋯”菜单。日历保留新建日程，同步、回收站和校园连接放入“⋯”。菜单支持键盘与 Escape，弹出层独立于列表，避免被滚动容器裁切。

说明段落和重复副标题已减少；课程覆盖不足、同步失败和操作错误继续显示。新手教程与离线手册位于设置的帮助分类。

大批量任务、通知、日历事件、专注记录与背景编辑采用局部滚动。较小窗口、用户主动展开附加组件或出现较长错误信息时，允许页面滚动，避免遮挡控件。布局检查使用合成账号与数据，测试脚本为 scripts/compact-ui-test.mjs；最终发行验收见 VALIDATION-V5.1.1.md。

安卓只更新版本标识，本次桌面布局不改变原生安卓界面。手机实机同步测试仍待完成。
