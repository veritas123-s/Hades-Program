# Hades V3.1 验证记录

- 新增详细使用说明及 Zeus 视角开发者手册，随安装提供离线 HTML、可编辑 Markdown 和关联技术资料。
- 登录页及设置页提供固定文档入口；不接受任意文件路径或网址，不解锁个人功能。
- 统一桌面版本为 3.1.0，修正设置页残留的 V3.0 文字。

## 验证状态

- `npm test`：105 项通过，无失败；包括帮助入口仅允许固定文件、拒绝路径和网址输入、个人命令继续锁定。
- `npm run build`：通过，生成六份离线帮助页面及桌面界面。
- `node scripts/help-test.mjs`：源码、实际 x64 与 ia32 程序通过。登录页两个入口、未知文档拒绝、锁定快照、个人接口拒绝、本地链接和目录锚点、宽窄视口均检查通过；两份手册截图已人工查看。
- `node scripts/account-gate-test.mjs <x64程序>`：登录隔离、停止等待、迁移记录保留、重新登录解锁和退出锁定通过。
- `node scripts/package-smoke.mjs <程序>`：x64 与 ia32 的实际 3.1.0 程序启动及主要界面检查通过。
- x64 实际包通过主进程账号入口访问原 HTTPS 服务，约 900ms 返回正常。使用从未创建的合成无效邮箱，不创建账号或投递邮件；不将该检查等同真实注册全流程。
- 源码隐私扫描无发现；两架构各检查 2329 个包内文本文件，无凭据和个人数据命中。
- 检查过根账号数据和现有账号子目录，升级前各有 10 条专注记录、累计 13348171ms。实际安装另在后续记录，安装包验证不代表已替换运行中的旧版。
- 初次 x64 NSIS 打包因输出文件暂时无法打开失败；基于同一已验证程序重试成功。最终交付使用成功生成的包，校验和另附发行目录。

本轮未改变服务端程序、数据库、账号密钥或公共服务地址；未重复发送真实测试邮件。V3.0.5 的本人真实收信确认属于前一版证据。
