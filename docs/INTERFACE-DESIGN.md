# 医栈通界面设计准则

2026-10-03。桌面规则适用于 Windows 与 macOS，Android 保持相同内容层级并使用原生 Compose 控件；保留桌面用户选择的主题和背景。

V6.1 补充通用控件边框、按钮高度、对话框圆角、键盘焦点、滚动条与减少动态效果。正文以13–15px为主，表单标签不再缩到11px；强调色用于主操作和当前状态。设置入口补齐当前位置标记。Android 使用清晰的线形导航图标、五入口底栏、系统安全区域和深色显示，页面标题22–24sp、正文14–15sp。

界面验收覆盖12个页面、8款主题、3种内容区尺寸，共290项实际检查；项目、知识、关联任务、日程、搜索、备份与重启另有操作验证。检查采用合成数据，截图不是用户真实任务或科研进度。最终各平台包仍须独立运行验收。

## 本次判断

校园快讯使用首页入口类，位于分组导航末尾，独立间距与旧圆角规则叠加后形成突兀的强调。全局入口、分类标题和功能入口的层级不稳定，首页大色块和快讯逐条卡片增加了视觉负担。

## 实施

- 今日概览与校园快讯并列，校园快讯继续一键直达。导航统一 34px 行高、16px 图标、6px 圆角；普通功能入口保持一致文字起点。
- 展开侧栏时，分类采用较轻的文字标题；分类仍可折叠。当前页面在被折叠分类中时，分类保留选中提示。
- 快讯用图文行与轻分隔线组织内容；来源操作与正文对齐。保留搜索、组织专栏、原文、删除和恢复。
- 首页时间、专注、截止共享一个指标表面；强调色用于数据和当前状态。顶栏辅助入口降低权重。
- 使用主题变量派生边框、悬停和选中颜色，不改个人配置。正常正文仍保持原有 13–15px 自适应范围。

## 参考与后续迭代

[Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)强调降低导航竞争、减少图标装饰、柔化边界；[Fluent 2 导航规范](https://fluent2.microsoft.design/components/web/react/core/nav/usage/)强调清晰分组与折叠后的当前位置提示。这些原则结合医栈通的功能结构使用，没有复制其品牌资产。

后续功能先复用同级入口、字号和间距，避免为单个模块另设圆角、强调色或大面积底色。审阅应同时看正常内容、长列表、无图、空状态、窄窗口和深色主题。每次视觉改动保留截图，再用合成数据验证主要操作。

`src/themes/interface.css` 是本次通用界面规则；主题配色和既有组件布局继续由原文件提供。
