Hades V3.0 · Windows 安装版

64 位 Windows 10/11：发送 Hades-Setup-3.0.0-x64.exe 一个文件。
32 位 Windows 10：使用 Hades-Setup-3.0.0-ia32.exe；该版本目前仅完成 64 位宿主上的兼容运行测试。
安装向导可选择位置，无需另装 Node.js、Python 或浏览器组件。
验证范围与已知限制见 docs/VALIDATION-V3.0.md。

1. 任务清单、四象限、番茄钟、时间记录、主题及随手记可直接离线使用。
2. Poseidon 助手 → 连接设置：填写你自己的 API 地址、密钥和模型调用名。
   支持兼容 OpenAI Chat Completions 的接口，Base URL 不要包含 /chat/completions。
   交大默认地址为 https://models.sjtu.edu.cn/api/v1，需要校园网或学校 VPN 及本人的授权密钥。
   其他服务按提供方给出的 Base URL 和模型名填写。可以刷新模型，也可以手填。
   模型列表获取失败不妨碍保存设置；若模型名正确，可以直接发送消息验证。
   更换服务地址必须同时填写该服务的密钥。API 使用费用或额度由你自己的服务账号承担。
3. 校园与课表：用你自己的学校账号登录，再同步课表。
4. 快报与提醒 → “扫码开通自己的微信早晚报”：
   第一步：点击“扫码登录腾讯云”，在官方浏览器页面选择微信扫码并授权你自己的账号。
   页面可能显示“腾讯云命令行工具”，本应用使用其公开授权协议，无需另装命令行工具。
   第二步：打开 pushplus 的微信绑定页面，登录、关注接收公众号，复制本人 Token 并保存。
   第三步：阅读并勾选资源、费用、任务课表摘要上传和每日推送确认，再点击开通。
   程序将建立上海区域私有存储、专用执行角色、提醒函数与两个定时器，并核验首次快照读写。
   开通后点击“发送一条测试提醒”；在微信实际收到后，点击“微信已收到”。
   每日北京时间08:00晨报、21:00晚报包含近期截止/逾期任务、重要任务、课程预习和复习。
   关机后仍用最后同步的数据；任务快照超过48小时或课表超过7天会提示重新核对。
   云服务费用由你的腾讯云账号承担，pushplus 的订阅、额度和激活规则以其页面为准。
   新账号可能须在腾讯云完成实名及 SCF/COS 服务开通；向导失败保留进度，登录同一账号后继续。
   云向导已通过隔离模拟与发行程序测试；不同真实账号的开通及自然定时送达仍需本人首次验证。
   退出临时授权或卸载应用不会关闭云端定时器。停用时可从“我的云资源与后续管理”打开控制台，
   关闭 veritas-morning、veritas-evening；长期停用可按需删除显示的专用函数、存储桶、角色和策略。
   安装包不包含作者的学校密钥、云端权限、微信接收配置或私人数据。学校 API 不会上传云端。
5. 关闭窗口会收起到托盘；完全退出请在托盘菜单选择“退出（保存并暂停计时）”。
6. 数据保存在当前 Windows 用户的 AppData/Roaming/AI-VERITAS 中。
   可在“设置与数据”导出备份；卸载默认保留个人数据。密钥仅以 Windows 加密形式保存。
7. 这是未购买代码签名证书的个人开发版本，Windows 可能显示“未知发布者”。
   请核对文件来自可信分享者，不要关闭系统安全防护。

同一台电脑的不同 Windows 用户各自配置；安装包不共享任何人的账号额度。

V3.0 新增：
8. 日程日历 → 导入 / 导出日历，可与支持 .ics 文件的日历工具交换日程。
   导入先预览，确认后才保存；重复文件不会重新创建已经删除的同一来源日程。
9. 顶部头像 → 账号与同步。已连接 Hades 账号测试服务，可注册、登录、找回密码并修改昵称。
   本机空间继续保留。首次进入账号可选择复制本机数据，或打开独立空间。
   开启同步后，任务、日程、课程、已保存专注记录及偏好可在其他电脑读取。
   同时修改产生冲突时先备份双方，再明确选择保留哪个完整版本；不会静默覆盖。
   校园登录、模型密钥、微信提醒配置和背景图片文件仍需各设备单独配置。
   账号服务当前使用受信任 HTTPS 的 IP 地址；好记的免费域名尚未配置。首次注册请核对真实验证码收信。
提供 Windows x64 和 ia32 安装包。macOS、Linux、Windows ARM 原生版本未提供。

V2.0 功能
日程与通知：今日课程、近期任务、学习通作业和通知。点击学习通扫码登录，在官方页面完成扫码，返回后立即同步。
学习通会话 Windows 加密保存；应用运行时每30分钟更新，关机时不拉取新作业。作业自动加入清单并进入现有早晚报。
仅有相对倒计时的期限标为估算，不自动填入精确DDL；缺少截止信息须本人核对。默认读取未归档学生课程，可勾选包含归档课程；每轮最多30门所选课程，每门20页作业；通知最近5页。
Poseidon 支持自动模型路由、默认模型及单次指定模型。日程与通知中的工作流可授权自动保存明确要求新建的任务，并可撤销新增。
专注空间可为本次番茄设置1–180分钟，也可以按结束时间补记1–1440分钟；暂停、休眠和重复区间不计入。
Hades 沿用原AI-VERITAS数据目录、应用ID及加密配置，升级前先退出旧版。学习通已在开发者本人账号实测；每位使用者仍需首次扫码，并核对自己的课程覆盖情况。

部分作业只含月日，显示估计年份并提示核对；不会自动写入任务截止日。未确认学期的课程默认放入历史与待确认，可以手动关注。旧版已入库的任务仍保留，可自行编辑或删除。

V2.1 新功能
- 日程日历：侧栏进入，可切换年/月/日、跳转日期；任务按截止日显示，课程按已同步课表显示。支持已完成任务筛选及任务编辑，没有截止日的任务在“待安排”。空白不代表无课，留意课表覆盖与更新提示。
- 超星通知清理：通知中心可单条删除、选择后批量删除、清理已读通知；“已删除”中可恢复。删除只影响 Hades 本地显示，不删除学习通服务器通知，同步后不会重新出现。任务和课程不会被一并删除。
- 动态反馈：弹窗弹出、日历与页面进入、助手侧栏滑入、按钮按压和操作提示。遵循 Windows 的减少动态效果偏好。


V2.2 新功能
- 首页、日程日历、校园课表共用日历；可按年/月/日查看任务、课程和手动日程。首页取消重复的课程和任务推荐面板。手动日程可新建、编辑、删除和恢复；目前手动日程仅保存在本机日历，需微信提醒的事项请创建有截止时间的任务。
- 清单可独立创建、重命名、删除与恢复。删除清单默认将任务保留在收集箱，也可勾选同时将任务放入回收站；专注历史不受影响。收集箱可清空任务，保留默认入口。
- 日历可删除课程，在 Hades 内隐藏，后续同步保持隐藏；日程回收站可恢复，不改学校服务器。任务、专注记录、超星通知沿用各自回收站。便笺提供删除和恢复最近一次内容；成绩缓存可清除。
- 七套内置主题：鎏金殿堂、晴日纸间、午夜星图、紫雾花园、轨道时代、千禧漫游、海盐来信。轨道时代使用构成主义与太空海报设计语言，不包含政治宣传口号。四款新主题使用原创 SVG 图画。
- 主题与小组件中可选择本机 PNG/JPEG/WebP 背景（20MB以内），调整浓度、模糊、位置与布局，并保存自己的配色主题。背景转为最长边2560像素的PNG，剥离原图元数据；不上传到云端。删除自定义主题可恢复，已存图片为恢复保留在本机。
- 完整备份包含清单、手动日程、课程回收站、自定义主题和图片，API密钥及校园会话仍不进入普通备份。数据格式升级至第4版，升级前自动保存旧文件；请先从托盘退出旧版，再打开新版，避免同时写入数据。

V2.3 新功能
- 通知中心默认只呈现近30天通知与近期未完成作业；过往、已完成、已截止及学期不明的事项进入“历史与待确认”。
- “管理关注课程”可以选择自动筛选、始终关注或不关注。关注设置立即影响显示，下次同步用于自动任务入库。
- 删除通知同时影响全部、未读、助手摘要，兼容通知ID与UUID；删除作业同时把对应本机任务放入回收站，可恢复。删除不改变学习通服务器。
- 旧版已经入库的任务保留在任务清单，历史来源事项从通知推荐和助手摘要排除；需要清除时请在本机删除对应任务或作业。
