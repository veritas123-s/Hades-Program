Hades V3.2 · Windows / Android

64位 Windows 10/11 使用 Hades-Setup-3.2.0-x64.exe；32位 Windows 10 使用 ia32 包；安卓手机使用 Hades-3.2.0-Android.apk。
安装包已经包含运行环境和两份离线手册，无需另外安装开发工具。

首次打开先注册或登录。未登录时个人功能锁定，但可点击“使用说明”阅读帮助。
登录页、设置与数据均提供手册入口，也可直接打开安装目录“帮助文档”中的 HTML。
使用说明：USER-GUIDE.html。Zeus 开发者手册：DEVELOPER-HANDBOOK.html。
可使用浏览器目录、查找及打印功能。可编辑原稿为同名 Markdown 文件。

升级前从托盘选择“退出（保存并暂停计时）”。关闭窗口可能只收起到托盘。
数据沿用 AI-VERITAS 目录，首次进入账号按提示明确选择是否迁移自己的旧数据。
每人使用自己的 API、校园和云提醒配置。请只分享安装包，不分享个人数据目录或密钥。

shsmuveritas.com 尚待 ICP 备案，本版继续连接原有受信任 HTTPS 账号测试服务。
手册说明各模块、同步范围、删除恢复、数据备份及已知限制。
