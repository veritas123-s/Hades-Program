# 校园快讯订阅

在校园快讯展开「筛选与订阅」，填写订阅关键词，或勾选主题的「订阅」，保存后在「我的订阅」查看命中的文章。关键词用逗号分隔；订阅关键词不区分英文大小写，匹配标题、摘要与来源。主题采用关键词规则分类，可能出现多分类或漏分，并非发布者的官方分类。

「我的订阅」按相关程度和发布时间排序。「最近24小时」继续按时间展示；分类下拉和搜索框可进一步筛选。屏蔽关键词或主题优先于订阅；重置只清除筛选和订阅条件，保留已关注来源、历史文章与删除记录。取消关注来源仍按原功能执行。

订阅条件保存在当前登录账号本机。采集仍沿用公开来源与每小时自动采集，不新增邮件、微信、系统推送或后台常驻服务；应用关闭时不会采集。公众号索引可能延迟或遗漏，不能把没有结果等同于没有发布。现有手动文章收录入口保留。
