# 医栈通 Medstack V5.0

开屏宣言：**医栈事，一站通**。助手继续使用 Poseidon 名称。

## 安卓安装与电脑同步

安装正式签名 APK，无需安装 Node.js、Pi 或开发环境。最低 Android 9。首次打开注册或登录医栈通账号，在手机与电脑端使用同一账号并分别开启同步。课程数据由电脑端连接教务系统后同步；手机可以查看课程和日程、编辑任务、记录专注时间。

出现同步冲突时，先核对两端内容再选择版本。模型密钥、校园会话与云厂商凭据各设备独立配置，不随业务数据同步。

旧安卓调试包使用不同包名；新版本安装为独立应用。先确认同一账号云端数据已同步，再在新版登录。未上传的旧版离线数据不会自动导入，请保留旧版直至核对完成。

## Poseidon 与 Pi

桌面、安卓共同使用官方 `@earendil-works/pi-agent-core@1.0.0`。框架负责工具执行循环，医栈通负责网络请求、加密存储、数据校验和任务写入。每轮最多6次模型请求。没有任意终端、文件或系统权限。

安卓的“助手”页可配置自己的 HTTPS Base URL、默认模型和 API 密钥。“附带任务与日程摘要”默认关闭。启用后仅传任务、日期和课程摘要；不传账号令牌或密钥。模型可调用只读摘要工具，任务卡片核对后点“核对并添加任务”。学校 API 需要校园网络或 VPN。

Pi 提供执行机制，不保证模型推理正确。没有支持工具调用的模型不能完成多步骤工具工作流，仍可返回普通答复或 JSON 草稿。致远接口实网兼容性与安卓实机验证分别记录，不用合成测试替代实网验收。
