# 医学学习与科研 · 工作台

本轮目标：在现有 Windows Medstack 内形成项目、任务、日程、知识记录和 Poseidon 的可运行闭环。沿用现有登录门禁、账号物理隔离、八主题、原子存储和可恢复删除。

## 实现与验收

- 项目：目标、阶段、截止日期、里程碑；关联已有或新建任务、日程，汇总进度与专注时间。
- 知识库：学习笔记、文献阅读、实验记录、会议纪要模板；全文检索、标签、修订历史和恢复；原文以纯文本显示。
- 工作台：项目概览、最近知识、近期安排、跨模块搜索、回收站及操作记录。
- Poseidon：按既有摘要开关读取项目概览；知识正文另需逐篇允许。工具只读，任务仍由用户确认草稿后入库。
- 数据：本机 schema 6 增加 workhub；完整备份包含新模块。已有云同步继续使用 schema 5 协议，项目/知识记录只保存在当前账号本机，界面明确标记；从云端恢复任务不能清除本机 workhub。不改线上账号服务或自动上传科研正文。
- 验收：旧数据迁移、重启、失败事务、软删除恢复、助手授权边界、云端兼容、真实 Electron 操作与发行包检查。

## 边界

本轮为个人医学工作台。组织账号、服务端角色权限、多人并发编辑、在线签批、机构级防篡改审计和临床病历管理不在已实现范围。业务操作记录用于追溯本机操作，不作为合规审计证明。Android 保持归档，小程序不修改。
