# Hades V3.2 验证记录

桌面 V3.2 已实际安装，安卓为调试测试包，实机验收由用户明确推迟到后续。V4 继续开发，不能据此宣称所有手机版功能已经验收。

## 已检查

- 桌面规则测试 107 项、服务端测试 4 项、隔离安全模拟 14 项均通过；桌面实际 UI 检查 18 项及 x64 发行程序启动通过。
- 构建通过，依赖审计无已知漏洞报告，x64 包内 2328 个文本资源隐私扫描无命中。
- Android GitHub 构建和 Lint 通过，产生调试 APK。未完成手机安装、双端真实同步和稳定发布签名验收。
- 腾讯云既有实例完成后台升级，命令返回成功。公网 /health 返回 3.2.0；无 Origin 和错误 Origin 返回 403，合法 Origin 的未登录会话返回 null；安全响应头已确认。没有发送新的测试邮件。
- 实际安装前备份业务数据、账号目录、加密配置及快捷方式。旧根目录 10 任务，账号目录 12 任务；两处均 10 条专注记录，累计 13348171 毫秒，所有专注区间逐条比对一致。
- 账号数据仅发生现有 validateState 的标准化：新增导航/教程默认值、规范化课程字段及一个任务的 repeatParent；完整标准化结果与实际保存内容一致，任务数量与原始专注记录未改变。
- 桌面及开始菜单 Hades 入口指向实际安装目录，无旧 VERITAS 快捷方式；加密配置保持。
