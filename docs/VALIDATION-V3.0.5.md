## 注册入口实网修正

首次安装后用户反馈仍无法发送。服务器记录重发接口403，原生环境复现错误码为 `MISSING_OR_NULL_ORIGIN`：Electron与Node网络自动附带Fetch Metadata，而旧的内存测试只构造Request，未覆盖这组请求头。已修正客户端携带配置中的HTTPS Origin，服务端来源校验保持开启，陌生来源仍返回403。更新后的认证库回归包含真实请求头；实际x64发行程序通过本机正常启动环境及真实HTTPS调用验证，约1秒返回正常。检查采用从未创建的合成账号，不发送真实邮件；不能代替真实用户收信验收。

本次仍使用3.0.5版本号，安装包内容与校验和已更新。修正版已在用户退出后再次备份并实际替换，个人记录及加密配置保持，快捷方式指向新版；从实际安装目录启动的隔离验证实例完成真实HTTPS入口调用（约1.3秒）。x64修正版登录保护回归通过；ia32重新构建并完成包内隐私检查，本次新增来源头的实网验证使用x64。用户随后在新版重新注册，已亲自确认收到验证码邮件；这确认了实际注册投递链路恢复，尚不代表验证码提交、账号迁移或跨设备同步全部验收。
