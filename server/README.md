# Hades 账号服务

使用已有腾讯云 CVM，不需要 CloudBase、独立数据库或共享开发者模型密钥。测试后台已启用公网 HTTPS，通过服务器上的合成账号测试、服务重启和真实中文邮件投递检查。安装桌面程序不需要用户自己安装此后台。两个真实账号跨电脑的完整验收仍待完成。

## 组成

- Node.js 24.15 或更高版本；生产部署使用受支持的 LTS 版本。
- Better Auth 负责密码散列、邮箱验证、会话、验证码和密码找回；Nodemailer 负责通过管理员提供的 SMTP 发送验证码。
- SQLite 保存账号及每个账号独立的同步文档。比较版本后才写入，保留最近 10 次替换前的快照。并发冲突交给客户端核对，禁止无提示覆盖。
- 服务只监听 `127.0.0.1:4318`；Caddy 提供公网 HTTPS，并覆盖转发的客户端 IP，供限流使用。
- 任务、清单、日程、课程、已保存专注记录及主题偏好进入同步。学校登录、模型密钥、微信令牌、背景图片文件和运行中的计时不上传。

## 部署前检查

核实实例和系统、既有 80/443/4318 端口占用及已有服务。在独立目录部署，建议 `C:\ProgramData\HadesServer`；不能清空或覆盖其他服务。服务进程用专用低权限身份运行，仅该身份和管理员能读数据目录。

准备一个已验证的公网 HTTPS 地址，以及专用验证码邮箱的 SMTP 主机、端口、账号、授权码和发件人。公网 IP 不等于域名；如使用 IP 证书，须单独验证签发工具和自动续期，不使用自签名证书或关闭证书验证来代替。不要在聊天、Git 或安装包中填写真实授权码。

1. 保留仓库中的 `server/` 和 `src/` 相对结构，执行 `npm ci --omit=dev --prefix server`。
2. 将 `config.example.json` 复制到独立数据目录的 `config.json`，填入 HTTPS 地址和 SMTP 配置。`secret` 由服务器安全随机生成至少 32 字节，保持稳定，不能直接使用示例文字。
3. 设置 `HADES_SERVER_DATA` 为该数据目录。启动 `node server/index.mjs`；本机访问 `/health`，先验证邮件发送和合成账号隔离。
4. 使用经验证的 Caddy 配置启动 HTTPS。只开放所需端口，不开放 SQLite、4318 或 Caddy 管理端口，不改动原远程登录防火墙规则。
5. 配置低权限开机运行、进程异常重启与数据库定期备份。在升级前停服务并备份 SQLite 主文件及 WAL/SHM，或使用 SQLite 在线备份接口；不要只复制正在写入的主文件。
6. 从客户端机器验证 TLS、邮件和服务重启后，把公开 HTTPS 根地址写入 `electron/accounts/config.json`，生成测试安装包。正式推广前继续验证真实注册、找回密码、账号隔离、断网重连和双端冲突，不把合成发件箱测试表述为真实用户验收。

禁止把数据目录或服务器日志放进公共 Web 目录。数据库备份属于私人账号数据，不能加入源代码仓库。快照历史不是灾难恢复备份；应配置独立的备份保留策略并实际试恢复。

设置 `HADES_SERVER_DATA` 后运行 `node server/backup.mjs` 可创建一致的在线 SQLite 备份，包含 WAL 中已提交的数据，并附带恢复会话所需的服务配置。文件写入数据目录内的 `backups/`，仅在完整性检查通过后从 `.pending` 改为正式目录。失败时保留现有数据与备份；工具不自动清理历史备份。备份包含邮箱凭据和账号数据，须沿用数据目录的严格 Windows 权限；同盘备份不能替代异地灾难恢复。

### Windows 上配置 QQ 邮箱

在服务器本机运行 `configure-windows.ps1 -Email <发信QQ邮箱> -BaseURL <公开HTTPS根地址>`，在密码框中填写 QQ 邮箱生成的 SMTP 授权码。不要把授权码放在命令参数中。窗口只保存配置，不发送邮件、不开放端口，也不代表服务已上线。

该表单为首次管理员配置准备：使用 QQ 的 `smtp.qq.com:465`，生成新的服务端密钥或保留已有密钥，将专用数据目录及已有配置的权限限制为当前配置身份、管理员和 SYSTEM；替换配置前保留备份。后续部署须另外给专用服务身份设置必需的目录权限。再次使用此表单会重设权限，需在维护窗口操作并重新核验服务身份。表单目前为英文，尚未在实际服务器完成交互验收。

Windows PowerShell 5 的默认管道编码可能损坏中文脚本。维护或投递测试使用 UTF-8 文件交给 Node.js 执行，不直接把中文脚本通过默认管道传入。正式注册模板已检查 UTF-8 源文件，邮件主题和正文经 MIME 解码比对，并由收件人确认中文实际显示正常。

### 本次部署边界

账号进程与每日备份使用 LOCAL SERVICE，HTTPS 使用 NETWORK SERVICE。账号数据及 SMTP 配置只向前者、SYSTEM 和管理员开放；证书目录只向后者、SYSTEM 和管理员开放。后台与管理监听仅在回环地址，公网新增 TCP80/443。每日备份已执行成功；开机触发和异常重启已配置，但没有为测试重启整台服务器，也尚未跨越证书自然续期时间。

当前客户端连接经过公信 CA 验证的 IP HTTPS 地址。免费易记子域名尚未配置。中国大陆实例的域名接入需要先核实备案条件；不能将公共免费子域名直接描述为可长期使用的正式地址。参考 [腾讯云备案说明](https://cloud.tencent.com/document/faq/243/19630)。
